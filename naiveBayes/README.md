# Naive Bayes Sınıflandırma Projesi

Bu proje, **Yapay Zeka ve Veri Mühendisliği** **Makine Öğrenmesi** dersi kapsamında hazırlanmıştır. 

## Proje İçeriği
- **Algoritma:** Gaussian Naive Bayes
- **Kütüphane:** Scikit-Learn (sklearn)
- **Amaç:** Veri setleri üzerinde olasılıksal sınıflandırma yaparak model başarısını ölçmek.

## Dosyalar
- `xxnaiveBayesScikitLearn.ipynb`: Kodların ve analiz raporunun bulunduğu ana Jupyter Notebook dosyası.
- `data/`: (Eğer varsa) Kullanılan veri setlerinin bulunduğu klasör.
